# 🛣️ Estrada de Wakanda

Este projeto em C processa dados de uma estrada fictícia em Wakanda, calculando qual cidade possui a menor vizinhança com base em suas posições. Ele lê arquivos de entrada, organiza as cidades e fornece análises sobre o trajeto.

## 📁 Arquivos

- `main.c`: Arquivo principal com a função `main`.
- `cidades.c`: Implementação das funções de leitura e cálculo.
- `cidades.h`: Header com os protótipos e structs.
- `estrWakanda.txt`: Arquivo com os dados da estrada.
- `Resultado.txt`: Gera os resultados dos testes realizados.

## 🚀 Como compilar

Use o comando:

```bash
gcc main.c cidades.c -o cidades
